# DSP meter (`HX_DSP_METER`, `tools/features/dsp_meter.py`, `src/m4/dsp_meter.s`) [verified on unit]

Each block's DSP cost and the blocks' total in the Edit view, and each model's cost in the model browser. Status tags as in [conventions.md](../conventions.md).

Each block in the Edit view shows its DSP cost in whole per cent, and the top right corner the blocks' total as DSP Disp says. In the model browser, each listed model's cost shows between its icon and its name (`dsp_browser` in `src/m4/dsp_meter.s`, chained after the browser's paint, literal `0x28d96df0`; see [m4/model-browser.md](../m4/model-browser.md)): at the model level only (`view + 0x40` = 2), each visible row's item priced by `0x28e01d50`, in white at scale 2, centred between the row's icon's right edge (from its widget's x, width and anchor) and the names, after the level and length calls and under the widget lock. The names move from x 44 to 60 to make room (the constructor's `movs r3, #0x2c` at `0x28d90f72`, the only write of the name list's x; it moves the category pages' names too). No widget covers the strip between icon and name, so each paint wipes every row's strip in black first, and the first paint at another level wipes them once. `src/m4/dsp_meter.s` is chained (`chain_ptr` on the literal `0x28d96da0`) after the Edit view top half's stock paint `0x28dc27f8`; `tests/test_dsp_meter.py` runs it in unicorn (`tests/m4emu.py`). The images in [dsp-meter-log.md](dsp-meter-log.md) were built on the old `dsp-meter` branch (`HX_DSP_METER=1`, patch_menu.py hooks before the features engine); the feature module's code is theirs, chained instead of calling the stock paint itself.

- **HX Stomp XL DSP Meter**: Edit block percentages are [verified on unit]; Total and Browser labels are [verified offline]. The XL Edit painter `0x28dc5938` uses the same eight image widgets at `view + 0x4a4 + 0x24*k`. `dsp_paint_xl` reads costs from the XL DSP state at `0x2844c5e8`, chooses the second-row record when the slot model `0x2812d3cc` has category byte `+0x3f` set, and draws the rounded whole-percent value inside each visible block icon. The XL settings page exposes **Model Browser**, **Edit Blocks**, and **Total** (Small, Large, Off). Browser cost lookup uses the XL model-list APIs; its label column moves from x 44 to 60.

How it got here, image by image: [dsp-meter-log.md](dsp-meter-log.md). The costs it shows: [m4/dsp-cost.md](../m4/dsp-cost.md).

## Model Browser, Edit Blocks and Total settings [verified offline, unicorn; on unit from RAM, 2026-11-14, as the earlier Meter (Both, Browser, Blocks, Off) and Total (Off, Small, Large): Total Off, Small and Large, and Meter Browser (the browser's numbers shown, the blocks' hidden); Meter's Blocks value offline only]

Global Settings › DSP Usage Display: **Model Browser** (virtual `0xe5`, container 107 bits 12..15: On, Off), **Edit Blocks** (`0xe3`, 107 bits 4..7: On, Off; it held the earlier Meter, so a unit that set Meter may read Edit Blocks Off) and **Total** (`0xe4`, 107 bits 8..11: Small, Large, Off). `read_settings` folds the two On/Off settings into one word: bit 0 hides the Edit view's numbers, bit 1 the browser's. The fields sit past the retired DSP Display field `0xd1` (bits 0..3), which units may still hold a value in. All read 0 when unset, so a unit that never set them shows the numbers everywhere and the Small total. On and Small come first for that reason: a unit that set the retired `0xd1` has container 107 stored, so its new fields read 0, not their defaults.

- Both paints read the three settings with `hxtra_setting_get` before taking either lock (`read_settings`), as the GR meter does.
- **Off** never calls the total widget's visibility, erase or draw: a hidden widget erased every paint would black out the title's pixels under its last text, which is the overlap this setting is for. Leaving Large hides and erases the widget once (`large_shown`).
- **Small** is the 3x5 glyph total of the images before `a759ce1`, at 2x, right-aligned at x 316 with its top at y 232, plus a `/` glyph. It is framebuffer only, so each paint first wipes the widest total's room (46x10 at x 270, y 222) when the last paint drew one (`small_drawn`), and a change to Off or Large wipes it once.
- Model Browser Off leaves the browser's names at x 60, where the build moves them; the name list's x is set once, by its constructor.
