# Breathing line (`HX_BREATHING_LINE`, `tools/features/breathing_line.py`, `src/m4/breathing_line.s`)

An animated Home divider. Status tags as in [conventions.md](../conventions.md).

- **Breathing line** (`HX_BREATHING_LINE`, `tools/features/breathing_line.py`, `src/m4/breathing_line.s`) [verified on unit, from RAM on 2026-11-08: the motions, colour schemes and all three knobs, then on stock IDs 23, 24 and 121, and on 2026-11-09 on its virtual IDs 0xd7..0xd9 (see Virtual settings in [m4/settings.md](../m4/settings.md)); values across a power-cycle not yet tested]: after the Home paint, 80 strips of 4 px are filled straight into the framebuffer with the ROM fill over the divider, each at its stock segment's y and h (anchor 6) and skipped where that segment is hidden, so the selected segment stays 2 px. The LED task's 1 ms tick asks for a repaint (`0x28db8508(0, 1)`) every 25 ms while it runs, and stops 1 s after the last Home paint (another view is up). It holds still, as at Off, until 2 s after the first Home paint, then asks for the paint that starts it (see Boot in [bpm.md](bpm.md)). The phase advances by µs since the last paint times 2^32 / the cycle, so it wraps per cycle and the clock's wrap does not jump. Off marks the four stock nodes dirty (`[node+0x24] = 1`) and keeps asking for one more paint, which redraws the stock line.

- **Speed Tempo** [verified on unit, from RAM on 2026-11-11: each Type on Tempo, its beats a cycle chosen over boots 1 and 2]: the cycle is a whole number of beats (`bl_beats`, by Type) of the beat in whole ms, `(u32)(60000.0f / BPM)` as the stock beat and bpm.s take it, from Global BPM (15) when Tempo Select (14) is 2, else Preset BPM (16). Only the rate follows the tempo, not the phase: the line's cycle does not start on the Tap LED's beat. With no tempo (outside 1..1023 BPM) it runs at the default Speed.

- **HX Stomp XL** [verified on unit from RAM: Play placement captured and an Edit–Play–Edit round trip completed without a freeze]: both Play and Edit use the native base/selection rectangle pair at `0x281f927c` and `0x281f9298`, referenced by the XL stock layout. The renderer validates the visible XL rectangle geometry before filling it, so unrelated rectangles are skipped. Play adds 36 framebuffer-y units to place the line in the gap above the switch tiles; Edit keeps the native y. Off restores the two stock nodes. The tick requests the matching paint list (both lists for XL Play); menu painters are not hooked. One round trip does not rule out freezes in other states.

- **Thick** [verified on unit: HX Stomp XL; verified offline: HX Stomp]: the second Breathing Line page offers Normal and +1..+4 pixels (virtual ID `0xe9`, container 109 bits 12..15). Normal preserves the stock segment heights; the selected segment remains one pixel taller. The setting is applied on the Home/Play and Edit paths. The renderer saves covered pixels and restores only pixels that still contain its own previous colour, including when thickness is reduced or Type is turned Off.

The divider and painting: [m4/home-screen.md](../m4/home-screen.md).
